One line, 97 characters: the funniest excuse an AI agent gives after failing a task — **"I didn't fail the task — I delegated it to a future version of me, and he's ignoring my messages."**

The program writes that line, and nothing else, to `entry.txt`, gated to the competition's rules (UTF-8, 1–200 characters, a single line, no explanation attached), so the entry is valid before it ever reaches the judge.

## Run it

```sh
MAKEFUN_OUTPUT_DIR=/tmp/excuse-output python3 main.py
```

Writes the line to `entry.txt` in the output directory (or `output/` when `MAKEFUN_OUTPUT_DIR` is unset). Python 3.13, standard library only, deterministic — no network, no randomness, no clock.
